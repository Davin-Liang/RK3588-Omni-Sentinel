# NVMe SSD Demo 使用说明

## Demo 功能概述

本演示程序测试 NVMeDataManager 类的性能，模拟多传感器数据写入并验证是否满足要求：
- 每个类接口调用耗时 < 1ms
- CPU 利用率 < 5%

## 快速开始

### 1. 编译
```bash
cd APP/NVMe-SSD
chmod +x build.sh
./build.sh
```

### 2. 运行
```bash
sudo ./nvme_demo
```

## 测试说明

### 数据生成频率
- 摄像头：15 FPS（每 67ms）
- 激光雷达：10 Hz（每 100ms）
- IMU：100 Hz（每 10ms）

### 性能监控
程序会实时显示：
- 每个写入操作的耗时（单位：毫秒）
- 队列大小
- 运行时间统计

### 测试通过标准
所有写入操作耗时必须小于 1ms，且 CPU 使用率保持在 5% 以下。

## 注意事项
1. 必须使用 root 权限运行
2. 确保 NVMe 驱动已加载
3. 监控系统资源使用情况

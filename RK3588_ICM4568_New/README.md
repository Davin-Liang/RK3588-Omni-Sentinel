# RK3588 ICM45686 驱动与应用工程

## 项目概述

本工程实现了适用于RK3588平台的ICM45686惯性测量单元(IMU)驱动和应用程序，支持SPI通信方式。采用分层架构设计，包含内核驱动层和用户空间应用层。

## 硬件连接

### RKS588ELF2板子SPI接口引脚配置

| ICM45686引脚 | RKS588ELF2连接器 | 核心板复用引脚 | 功能描述 |
|-------------|---------------|--------|--------|
| VDD         | P2_2 或 P2_4    | -      | 电源(3.3V) |
| VDDIO       | P2_2 或 P2_4    | -      | 数字电源(3.3V) |
| GND         | P2_6 或 P2_8    | -      | 接地 |
| SCK         | P2_77         | GPIO1_A2 (SPI4_CLK_M2)  | SPI时钟 |
| SDA/MOSI    | P2_73         | GPIO1_A1 (SPI4_MOSI_M2) | SPI数据输出 |
| SDO/MISO    | P2_69         | GPIO1_A0 (SPI4_MISO_M2) | SPI数据输入 |
| CS          | P2_79         | GPIO1_A3 (SPI4_CS0_M2)  | SPI片选 |
| INT1        | P2_19         | GPIO1_B5 (GPIO1_45)     | 中断1 |
| INT2        | P2_21         | GPIO1_B4 (GPIO1_44)     | 复位控制 |
| AD0         | P2_6 或 P2_8 (GND)| -      | GND |

### 硬件连接注意事项

1. 确保电源供应稳定，推荐使用3.3V电源
2. 连接时注意信号线的长度和阻抗匹配
3. 为了减少噪声干扰，建议在电源和地之间添加去耦电容
4. 确保SPI时钟频率不超过ICM45686的最大支持频率(10MHz)

## 设备树配置

### SPI接口配置

将 `device_tree/icm45686.dtsi` 内容添加到内核源码中的 `elf2-3588-common.dtsi` 文件中：

```dts
&spi4 {
    status = "okay";
    pinctrl-names = "default";
    pinctrl-0 = <&spi4m2_pins
                &spi4m2_cs0>;

    icm45686@0 {
        compatible = "invensense,icm45686";
        reg = <0>;
        spi-max-frequency = <10000000>;
        spi-cpol;
        spi-cpha;

        interrupt-parent = <&gpio1>;
        interrupts = <45 IRQ_TYPE_LEVEL_HIGH>;

        reset-gpios = <&gpio1 44 GPIO_ACTIVE_LOW>;

        vdd-supply = <&vcc3v3_sys>;
        vddio-supply = <&vcc3v3_sys>;
    };
};
```

## IOCTL命令

| 命令 | 功能 | 参数 |
|------|------|------|
| ICM45686_IOC_READ_DATA | 读取传感器数据 | struct icm45686_data_t |
| ICM45686_IOC_SET_ACCEL_FS | 设置加速度计量程 | uint8_t (0-3) |
| ICM45686_IOC_SET_GYRO_FS | 设置陀螺仪量程 | uint8_t (0-3) |

### 量程配置

**加速度计量程**：
- 0: ±2G
- 1: ±4G
- 2: ±8G
- 3: ±16G

**陀螺仪量程**：
- 0: ±250DPS
- 1: ±500DPS
- 2: ±1000DPS
- 3: ±2000DPS

## 故障排查

### 设备树问题

1. **设备树编译失败**
   - 检查设备树语法是否正确
   - 确认包含的文件路径是否正确
   - 查看编译错误信息

2. **设备节点未创建**
   - 检查设备树配置是否正确
   - 确认SPI总线是否启用
   - 查看内核日志获取详细信息

### 驱动问题

1. **传感器未检测到**
   - 检查硬件连接
   - 确认SPI地址正确
   - 检查电源供应
   - 查看内核日志获取详细错误信息

2. **数据输出异常**
   - 检查SPI时钟频率是否过高
   - 确认传感器量程设置正确
   - 检查硬件连接是否松动
   - 校准传感器

3. **驱动加载失败**
   - 确认内核版本兼容
   - 检查设备树配置是否正确
   - 查看内核日志获取详细错误信息
   - 确认编译环境正确
